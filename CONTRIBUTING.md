# Contributing

Canonical guide on the docs site: [English](https://docs.gov.skin/en/community/contributing/) · [中文](https://docs.gov.skin/community/contributing/)

Build, test, and dev environment instructions for this repository are in the [README](./README.md); commit messages are enforced as Conventional Commits by commitlint + lint-staged, and style by ESLint + Prettier + Stylelint.

Security vulnerabilities: do not open a public issue; use the private reporting flow in [SECURITY.md](./SECURITY.md).
